## Selected Work

Client repositories are private. Each project below links to its case study.

### 🛒 [Alpha PetCare](https://www.darkonovex.com/our-projects/alpha-petcare) · [alphapetcare.lk](https://alphapetcare.lk/)

Pet supplies e-commerce — **live in production**. Three systems in one build: a Next.js
customer storefront, a React admin dashboard, and a NestJS + PostgreSQL + Redis API, with
real-time stock reservation, card and cash-on-delivery checkout, order tracking, and refund
handling. **Delivered in 12 weeks — one day ahead of schedule, 100% in-house.**

`Next.js 16` `React 19` `Tailwind CSS 4` `NestJS 11` `Prisma` `PostgreSQL 16` `Redis 7` `Docker`

### 🧊 [ShrinkModel](https://www.darkonovex.com/our-projects/shrinkmodel) · [shrinkmodel.com](https://shrinkmodel.com/)

Our own in-house product — **live in production**. Compresses GLB models up to 500 MB with
Draco or Meshopt, then renders the original and the compressed result side by side in one
scene, with a first-person walkthrough, so the cost of every setting is visible.
**Zero retention by design:** the output is streamed back and deleted within the request.

`Next.js 15` `Babylon.js 8` `WebGL` `NestJS 11` `glTF-Transform 4` `PostgreSQL 15` `Redis 7`

### 🧵 [DoubleD Fashion ERP](https://www.darkonovex.com/our-projects/doubled-fashion-erp)

A bespoke ERP engineered from scratch for a garment factory — **client deployment**. Nine
modules covering the full manufacturing process, stock and materials, and the entire employee
side from HR and attendance to performance and payroll. Built around the client's own process,
not adapted from an off-the-shelf platform. **20-week build, zero off-the-shelf.**

`React` `Vite` `PWA` `NestJS` `Prisma` `PostgreSQL` `Redis` `Nginx` `GitHub Actions`

### 🏛️ [Ancestra](https://www.darkonovex.com/our-projects/ancestra)

A Culture-as-a-Service marketplace connecting travelers with verified Sri Lankan hosts and
authentic cultural experiences — **in beta**. Traveler, host, and admin roles over a NestJS API
modelling host profiles, categorized experiences, schedules, capacity, and seats.

`Next.js 16` `React 19` `NestJS 11` `Prisma 7` `PostgreSQL` `JWT + Passport` `Google OAuth`

→ [All case studies](https://www.darkonovex.com/our-projects)
